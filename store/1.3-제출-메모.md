## 4. 데모 계정에 필요한 것

- [미확인] **번호만으로 지금도 들어가지는지.** 10/5~6 에 전화번호 로그인을 보강했다(자리표시자 번호 거절 · 번호 훑기 제한). 데모 번호가 PIN 없이 바로 로그인되는지 제출 전에 실제로 한 번 해 본다. 안 되면 심사 메모의 "No SMS code or password is required" 를 고치고 PIN 을 로그인 정보 칸에 적는다.
- [미확인] **골프 자료.** 데모 계정은 당구 전적만 있다(`store/listing.md` 10번째 줄). 골프를 등록정보·심사 메모에 올리면 심사관이 한국어로 바꿔 골프 홈을 열었을 때 빈 화면을 보게 된다 — 라운드 기록 한두 개를 넣을지 정한다. [결정]
- [미확인] **약관 동의 상태.** 데모 계정이 최신 약관에 동의돼 있지 않으면 로그인 직후 동의 창이 뜬다(막히지는 않는다).
- 카카오 로그인은 심사관이 자기 카카오 계정이 있어야 눌러 볼 수 있다. 데모 계정(전화번호)으로 같은 화면에 들어갈 수 있다는 것을 메모에 적어 둔다(위 초안에 있음).
- 애플 심사 정보 칸: 연락처 이름·전화·이메일은 1.2 때 넣은 값 그대로인지 본다.

## 5. 제출 전에 정할 것 [결정]

> **10/7 갱신:** 1번은 **[A]** 로 정해졌다 — 오너가 카카오를 열라고 해서 스위치를 켰고(6f1d1e9a), App Store Connect 의 심사 메모도 [A] 문장으로 고쳐 저장했다.

1. **심사 중 카카오를 보이게 할지.** 지금 계획은 "승인되면 연다"다. 그러면 심사관은 카카오 단추를 보지 못한 채 승인하고, 출시 뒤에 로그인 수단이 나타난다 — 심사 뒤에 켜지는 기능으로 지적될 여지가 있다(추정). 고를 수 있는 길:
   - [A] 제출 직전에 스위치를 켠다 → 웹 카카오도 그때 같이 열린다(1.2 앱에는 단추가 안 나오고, 한국어 화면에 "카카오로 가입했다면 웹에서" 안내 한 줄이 뜬다).
   - [B] 끈 채 제출하고 심사 메모에 사실대로 적는다(위 초안의 [B] 문장).
   - [C] 1.3 바이너리에서만 먼저 열리게 하는 장치를 따로 만든다(지금은 없다).
2. **골프를 등록정보(설명·키워드·스크린샷)에 올릴지.** 올리면 한국어에만, 그리고 심사 메모의 골프 문단 + 데모 계정 골프 자료가 같이 가야 한다.
3. **개인정보 라벨.** 카카오 SDK 는 자체 개인정보 매니페스트가 있다(추적 없음). App Store 라벨·Play 데이터 보안 설문에 카카오 회원번호·닉네임을 어떻게 적을지, 위치·사진의 용도 설명에 골프를 넣을지.
