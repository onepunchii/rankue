## 📨 Replit 개발자 전달용 프롬프트

**Polli 인증 시스템 + 프로필 인증 통합 리팩터링 요청**

---

### 📌 개요

Polli 플랫폼의 인증 시스템을 다음과 같이 리팩터링하여 사용자 경험을 단순화하고, 데이터 일관성과 보안을 확보하고자 합니다.

---

## ✅ 핵심 목표

1. **모든 비회원은 `guest_common` 계정**으로 통일
2. **회원가입은 프로필 인증 화면에서 진행**

   * 이메일 + 숫자 6자리 비밀번호
   * 성함 + 휴대폰 번호 함께 입력
3. **게스트는 설문 열람만 가능**, 회원만 설문 참여 가능
4. **앱/웹 내에서 비밀번호 변경 및 재설정 가능** (이메일 발송 없이)
5. **로그인 유지 기간은 30일** (JWT + localStorage 저장)

---

## 👤 사용자 인증 상태 구조

```ts
type AuthUser = {
  id: string;               // "guest_common" or "user_xxxxx"
  isGuest: boolean;
  isAuthenticated: boolean;
  email?: string;
  name?: string;
  phone?: string;
};
```

---

## 🔐 인증 흐름 상세

### \[1] 게스트 사용자

* ID: `"guest_common"`
* 상태: `isGuest: true`, `isAuthenticated: false`
* 기능:

  * 설문 열람 ✅
  * 설문 참여 ❌ (참여 시 "로그인 필요" 안내 모달)

---

### \[2] 프로필 인증 + 회원가입 (한 번에 처리)

* 위치: `프로필 인증 화면`
* 입력 항목:

  * 이메일 주소
  * 숫자 6자리 비밀번호 (예: `123456`)
  * 성함
  * 휴대폰 번호
* 처리 흐름:

  1. 서버로 정보 전송 → 회원 생성
  2. 기존 guest 데이터를 user 계정으로 이관
  3. JWT 발급 → localStorage에 `"polli_token"` 저장
  4. 자동 로그인 상태 진입

---

## 🔄 비밀번호 기능

### ✅ 비밀번호 변경

* 로그인된 상태에서만 가능
* 현재 비밀번호 → 새 비밀번호 입력
* 숫자 6자리 비밀번호만 허용 (`^\d{6}$`)

### ✅ 비밀번호 재설정

* 로그인 불가 시 진행
* 이메일 + 휴대폰 번호 입력 → 본인 인증 후 새 비밀번호 입력
* 이메일 전송 없음, 앱/웹 내에서 처리

---

## 🔐 보안 및 제한 사항

| 항목        | 설정                                           |
| --------- | -------------------------------------------- |
| 비밀번호      | 숫자 6자리만 허용 (`^\d{6}$`)                       |
| 비밀번호 해싱   | bcrypt 등 안전한 해시 알고리즘 사용                      |
| 로그인 시도 제한 | 5회 오류 시 10분 잠금 등 보안 설정 권장                    |
| 자동 로그인 저장 | `localStorage.setItem("polli_token", token)` |
| 토큰 만료 기간  | 30일                                          |
| 로그아웃 시    | `localStorage.removeItem("polli_token")` 처리  |
