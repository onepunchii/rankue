좋아요 정환님 👍 완전 좋은 방향이에요.
지금 **Polli Enterprise Research** 페이지는 기업용 리서치 서비스 소개만 되어 있어서,
기업들이 “다른 기업들은 어떤 조사를 했는지”를 한눈에 볼 수 있게 만드는 건 **신뢰도 + 실적 증명 + 신규 문의 전환율 상승** 세 가지를 동시에 잡는 훌륭한 개선이에요.

아래에 **UI 구조 + 데이터 구조 + 예시 카드 디자인**을 나눠서 정리해드릴게요 👇

---

## 🧩 1️⃣ 구조 개요

**📍 목표:**
방문자가 기업 카테고리별로 실제 진행된 설문 사례를 확인하고,
각 설문 카드를 클릭하면 세부 결과나 요약 페이지로 이동

**📊 구성 흐름:**

```
[카테고리 탭]  →  [기업별 설문 카드 리스트]  →  [개별 설문 상세페이지]
```

---

## 🗂️ 2️⃣ 카테고리 예시

```ts
카테고리 예시:
- IT·전자
- 금융·보험
- 식음료·유통
- 자동차·모빌리티
- 헬스케어·뷰티
- 공공·지자체
- 스타트업·서비스
```

각 카테고리를 클릭하면 해당 카테고리에 속한 기업들의 설문 사례 카드가 필터링돼요.

## 💳 3️⃣ 카드 UI 예시 (React + Tailwind + shadcn/ui)

```tsx
import { Card, CardHeader, CardContent, CardFooter } from "@/components/ui/card";
import { Badge } from "@/components/ui/badge";
import { Button } from "@/components/ui/button";
import { Star } from "lucide-react";

export default function SurveyCard({ company, title, date, category, highlight, image }) {
  return (
    <Card className="hover:shadow-lg transition rounded-2xl overflow-hidden">
      <img src={image} alt={company} className="w-full h-40 object-cover" />
      <CardHeader className="p-4">
        <div className="flex items-center justify-between">
          <h3 className="font-semibold text-lg">{company}</h3>
          <Badge variant="secondary">{category}</Badge>
        </div>
        <p className="text-sm text-gray-500">{date}</p>
      </CardHeader>
      <CardContent className="px-4 pb-2">
        <p className="text-sm text-gray-700">{title}</p>
        <div className="mt-2 flex items-center gap-1 text-sm text-violet-600">
          <Star size={14} className="fill-violet-500" /> {highlight}
        </div>
      </CardContent>
      <CardFooter className="p-4">
        <Button className="w-full bg-violet-600 hover:bg-violet-700 text-white text-sm">
          상세 보기
        </Button>
      </CardFooter>
    </Card>
  );
}
```

## 🧠 5️⃣ UX 추천 포인트

* **카테고리별 필터 버튼** → sticky로 상단 고정
* **카드 hover 시 그래프나 주요 수치 미리보기**
* **신뢰 로고 섹션 추가** (“이런 기업들이 Polli를 선택했습니다”)
* **하단 CTA** “우리 기업 리서치도 Polli와 함께하기 → [문의하기]”
