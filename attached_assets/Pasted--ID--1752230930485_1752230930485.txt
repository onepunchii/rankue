회원가입 없이도 **자동으로 기기나 환경 정보를 기반으로 ID를 부여하고 저장**하려면, 다음의 방식으로 시스템을 설계하면 됩니다:

---

## ✅ 목표 요약

* 회원가입 없이도 자동으로 고유 ID를 생성
* 기기 기반 정보 (예: 디바이스 ID, IP, 브라우저 등)로 세션 또는 계정 식별
* 이후 본인인증(PASS 등)하면 기존 ID에 연결

---

## ✅ 1. ID 부여 방식 (비회원 상태)

### 🔹 방법 A. **디바이스 기반 UUID 생성**

* 기기 고유 식별자 또는 조합으로 `hash` 또는 `UUID` 생성
* 예시 정보 조합:

  * User-Agent (브라우저 정보)
  * IP 주소
  * OS 정보
  * 브라우저 로컬 저장소 값 (localStorage)
  * Device Fingerprint (해시)

✅ 생성 예:

```js
const rawFingerprint = navigator.userAgent + screen.width + screen.height;
const userId = sha256(rawFingerprint); // or UUIDv5
```

**장점**: 회원가입 없이도 고유 ID 부여
**단점**: 기기/브라우저 변경 시 인식 불가 가능성 있음 (쿠키 또는 로컬저장소 활용 필요)

---

## ✅ 2. 클라이언트에서 저장 방법

### Web or App 공통:

* `user_id`를 **localStorage**, **secureStorage**, **cookie**, 또는 앱이면 **AsyncStorage**에 저장
* 로그인/재접속 시마다 `user_id`가 있는지 확인 → 있으면 그대로 사용

```js
if (!localStorage.getItem("user_id")) {
  const newId = generateUUID(); // 자체 생성 또는 서버 요청
  localStorage.setItem("user_id", newId);
}
```

---

## ✅ 3. 서버에 기록 및 관리

### Backend: Node.js 예시

```js
POST /track
Body: {
  user_id: "user_ab12345",
  device_info: {...},
  created_at: ...
}
```

서버 DB 예:

| user\_id      | device\_info            | created\_at      |
| ------------- | ----------------------- | ---------------- |
| user\_ab12345 | {"ua":"Chrome...", ...} | 2025-07-11 18:52 |

## ✅ 4. 이후 본인인증(PASS 등) 시 처리

* 본인인증 성공 → `user_id`에 실명 정보, 전화번호, ci 등 연결
* 이후부터 해당 기기 `user_id` = 인증된 실계정

---

## ✅ 5. 보안 및 중복 방지

* 동일 디바이스에서 재설치/로그아웃 후에도 `user_id`를 복원하려면:

  * **Device Fingerprint** + 서버 캐시 or
  * **Firebase Installation ID**, **UUIDv5(device info)** 등 사용
* 인증 후 `ci` 기반 중복 사용자 방지도 필수
