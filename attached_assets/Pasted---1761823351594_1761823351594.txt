```
📊 헤더 (요약)
├─ [로고] Polli x 강남구 실증특례
├─ [요약] 조사기간 / 응답자 수 / 문항 수
└─ [다운로드 버튼] PDF, Excel, 공유 링크

📈 섹션 1: 핵심 KPI
📊 섹션 2: 응답자 개요 (거주지·연령·성별)
📋 섹션 3: 주요 서비스 만족도 (Q1~Q10)
💬 섹션 4: 자유서술형 인사이트 (AI 요약 포함)
🧠 섹션 5: 정책 제안 및 개선사항
📁 섹션 6: 프로젝트 비교 / 히스토리 / 재조사 요청
```

## 💎 3️⃣ 핵심 섹션 설계

### 📊 (1) KPI 요약 카드

```tsx
const kpiData = [
  { title: "접근성 개선", score: 100, trend: "+3%", color: "#7C3AED" },
  { title: "투명성", score: 100, trend: "+2%", color: "#22D3EE" },
  { title: "환경 영향", score: 100, trend: "+5%", color: "#10B981" },
  { title: "공공 신뢰", score: 100, trend: "+1%", color: "#FB7185" },
  { title: "선택권 확대", score: 100, trend: "+4%", color: "#FACC15" },
];
```

각 카드에는 아이콘(`Accessibility`, `Transparency`, `Leaf`, `Handshake`, `Choices`)을 배치.
“직관성”을 위해 점수는 원형 게이지(`CircularProgressbar`)로 표현.

---

### 👥 (2) 응답자 개요

* **좌측:** 원형 그래프 (거주지 분포)

* **우측:** 요약 수치 카드

  ```
  총 응답자: 42명  
  강남구 거주: 38명 (90.4%)  
  타지역 응답자: 4명 (9.6%)
  ```

* 하단에 “응답자 분포 지도 (Mapbox)” 넣으면 정책 활용도가 급상승합니다.

---

### 🌈 (3) 주요 만족도 분석

리커트 5점 척도 항목(Q4~Q10)을 다음처럼 바꾸면 시각성이 확 달라집니다.

```tsx
<BarChart data={data}>
  <XAxis dataKey="question" />
  <YAxis domain={[0, 5]} />
  <Tooltip />
  <Bar dataKey="average" fill="#7C3AED" radius={[8, 8, 0, 0]} />
</BarChart>
```

→ 각 항목 평균을 막대 길이로 표현하고,
우측에는 “긍정 응답률 %” 숫자로 표시

> 예: “예약 과정이 쉬웠습니다 — 97% 긍정”

---

### 💬 (4) 자유서술형 의견 (AI 요약)

* **카드형 말풍선 뷰**

  ```
  “너무 감사합니다. 덕분에 잘 보냈습니다.”
  → 감정: 긍정 / 키워드: ‘감사’, ‘배려’, ‘신속’
  ```
* 하단에 “🧠 AI 요약” 버튼 클릭 시 자동으로:

  ```
  ▶ 전체 감정 요약: 긍정적(98%)  
  ▶ 주요 키워드: 접근성, 공감, 신속함  
  ▶ 개선사항: 홍보 확대, 시간대 다양화
  ```

---

### 🏛️ (5) 정책/지자체 개선 제안

Tag Bubble Chart / Word Cloud

```js
["홍보 지원", "운영시간 확대", "취약계층 바우처"]
```

→ Hover 시 퍼센트 표시, 클릭 시 해당 항목별 응답자 리스트 팝업

---

### 📑 (6) 보고서 생성 / 비교 섹션

* “📥 PDF 다운로드” 버튼 →
  AI 자동 보고서 생성:

  > “이번 실증사업은 접근성·공공신뢰 면에서 만점(100점)을 기록했습니다.
  > 향후 과제로는 홍보 채널 다양화와 시간대 확장 방안이 제시되었습니다.”

* 아래에는 “지난 조사와 비교 그래프” (예: 2024 vs 2025)
  → 변화율을 화살표로 표시

## 🧠 4️⃣ 데이터 구조 (Supabase 테이블 예시)

```sql
TABLE survey_responses (
  id uuid primary key,
  region text,
  satisfaction jsonb,
  kpi jsonb,
  feedback text,
  created_at timestamptz
)

TABLE ai_summary (
  survey_id uuid references survey_responses(id),
  sentiment text,
  keywords text[],
  summary text
)
```
