⑤ Prerender 자동 캐시 갱신

Polli는 뉴스·설문이 자주 바뀌니까 prerender 캐시도 주기적으로 갱신해야 합니다.

💡 자동 캐시 갱신 명령:
curl -X PURGE "https://service.prerender.io/https://www.polli.co.kr/"


이걸 Replit 스케줄러(크론)나 GitHub Actions로 하루 1~2회 실행하게 설정하면,
항상 최신 설문과 뉴스가 검색결과에 반영돼요.
