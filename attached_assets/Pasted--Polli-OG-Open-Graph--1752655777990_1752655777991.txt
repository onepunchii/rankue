좋아 정환아, 너의 **Polli 플랫폼** 링크가 **카카오톡 등에서 미리보기가 잘 뜨도록** 하기 위해 넣어야 할 **OG (Open Graph) 태그 세트**를 아래에 정리해줄게.

---

## ✅ Polli 링크용 기본 OG 태그 템플릿

```html
<!-- 기본 Open Graph 태그 -->
<meta property="og:title" content="Polli - 참여형 여론 플랫폼" />
<meta property="og:description" content="누구나 만들고, 누구나 참여하는 설문/투표 플랫폼. 지금 여론에 참여해보세요!" />
<meta property="og:image" content="https://www.polli.co.kr/assets/og-thumbnail.png" />
<meta property="og:url" content="https://www.polli.co.kr" />
<meta property="og:site_name" content="Polli" />
<meta property="og:type" content="website" />

<!-- Twitter용 (선택 사항) -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="Polli - 참여형 여론 플랫폼" />
<meta name="twitter:description" content="당신의 한 표가 세상을 바꿉니다. 투표하고, 결과를 공유하세요!" />
<meta name="twitter:image" content="https://www.polli.co.kr/assets/og-thumbnail.png" />
```

---

## ✅ 썸네일 이미지 만들기 가이드

**이미지 URL 예시:**
`https://www.polli.co.kr/assets/og-thumbnail.png`

**디자인 팁:**

* 크기: 1200 x 630px (카카오, 페북 공통)
* 텍스트:

  ```
  “당신의 의견이 필요해요!”
  지금 투표 참여하고 결과 확인하기
  Polli.co.kr
  ```
* 컬러톤: 파랑 (#0F62FE), 흰색, 밝은 회색

원한다면 DALL·E 이미지 프롬프트도 바로 만들어줄게 👉

---

## ✅ 적용 방법 (Replit에서)

1. `index.html` 혹은 SSR 렌더링에서 `<head>` 안에 위 태그들 삽입
2. 썸네일 이미지는 `public/assets/` 폴더에 업로드
3. 링크 배포 후, **카카오 디버거로 캐시 초기화**
   → [https://developers.kakao.com/tool/clear/og](https://developers.kakao.com/tool/clear/og)

---

## ✨ Polli에서 설문마다 동적으로 적용하려면?

**예시 코드 (Next.js나 Express):**

```js
res.send(`
  <html>
    <head>
      <meta property="og:title" content="${poll.title}" />
      <meta property="og:description" content="${poll.description}" />
      <meta property="og:image" content="${poll.thumbnailUrl}" />
      ...
    </head>
    ...
  </html>
`)
```
