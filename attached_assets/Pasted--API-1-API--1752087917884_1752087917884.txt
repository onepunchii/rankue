## 📌 **1단계: 네이버 뉴스 API 키 발급받기**

네이버 뉴스 API를 쓰기 위해서는 먼저 API 키를 받아야 합니다.

### 🔑 **발급 방법**

1. 네이버 개발자 센터로 접속
   👉 [**https://developers.naver.com**](https://developers.naver.com)

2. 로그인 후, 상단 메뉴의 **Application → 애플리케이션 등록** 클릭

3. 애플리케이션 등록에서 다음 항목을 입력

   * 이름(앱 이름): 자유롭게 작성
   * 사용 API: `검색` 항목 체크(네이버 뉴스 API는 '검색' 안에 포함됨)
   * 환경: 웹(Web) 또는 서버(Server) 선택 가능
   * 서비스 URL 및 Callback URL (서비스 주소 또는 개발 중일 땐 임시 주소 가능)

4. 등록 후, 애플리케이션을 클릭하면 **클라이언트 ID(Client ID)** 와 **클라이언트 시크릿(Client Secret)** 키를 받을 수 있습니다.

**예시**

```
CLIENT_ID: abc123def456ghi789
CLIENT_SECRET: jkl012mno345pqr678
```

## 📌 **2단계: 네이버 뉴스 API 요청 방법**

발급된 API 키로 REST API 요청을 보내면 뉴스를 가져올 수 있습니다.

### ⚙️ **요청 형식**

```
GET https://openapi.naver.com/v1/search/news.json
```

### 🔍 **필수 파라미터 예시**

| 파라미터    | 설명                            | 예시          |
| ------- | ----------------------------- | ----------- |
| query   | 검색할 키워드                       | 정치, 경제, 윤석열 |
| display | 한번에 가져올 뉴스 개수 (기본 10, 최대 100) | 10          |
| sort    | 정렬 기준 (sim=정확도순, date=날짜순)    | date        |

## 📌 **3단계: Node.js 코드 예제 (axios 활용)**

**✅ 코드 예시**

```bash
npm install axios
```

아래는 실제로 뉴스를 요청하는 예제 코드입니다.

👉 **naver-news-api.js**

```js
const axios = require('axios');

// 네이버 API 키 설정
const CLIENT_ID = "발급받은_CLIENT_ID";
const CLIENT_SECRET = "발급받은_CLIENT_SECRET";

// 네이버 뉴스 API 요청 함수
async function fetchNaverNews(query, display = 10) {
  const api_url = 'https://openapi.naver.com/v1/search/news.json';

  try {
    const response = await axios.get(api_url, {
      params: {
        query,
        display,
        sort: 'date', // 최신 뉴스순으로 정렬
      },
      headers: {
        'X-Naver-Client-Id': CLIENT_ID,
        'X-Naver-Client-Secret': CLIENT_SECRET,
      },
    });

    const newsItems = response.data.items;

    newsItems.forEach((item, index) => {
      console.log(`🔹 뉴스 ${index + 1}: ${item.title.replace(/(<([^>]+)>)/gi, '')}`);
      console.log(`🔗 링크: ${item.link}`);
      console.log(`🕒 날짜: ${item.pubDate}`);
      console.log('---------------');
    });

  } catch (error) {
    console.error('뉴스 API 요청 중 오류 발생:', error.response?.data || error.message);
  }
}

// 실행 예시
fetchNaverNews('정치', 5);
```

**위 코드 설명**:

* 발급받은 네이버 클라이언트 ID, Secret으로 인증 처리
* 지정한 키워드(query)로 최신 뉴스 5개를 가져옴
* 제목에서 HTML 태그 제거 후 출력 처리

## 📌 **4단계: 코드 실행**

## 📌 **⚠️ API 사용 시 주의사항**

* 네이버 API는 일일 최대 요청 건수 제한이 있습니다. (기본 25,000건/일)
* 상업적으로 사용할 경우 [네이버 오픈 API 이용약관](https://developers.naver.com/docs/common/openapiguide/#%EC%9D%B4%EC%9A%A9-%EC%95%BD%EA%B4%80)을 확인하여 준수해야 합니다.
* 뉴스 컨텐츠의 저작권은 네이버 및 각 언론사에 있으므로, 뉴스 원본 링크를 항상 명확히 제공하세요.
