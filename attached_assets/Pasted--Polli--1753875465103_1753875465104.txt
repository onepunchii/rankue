## ✅ Polli “국회의원 활동 지수” 프로젝트 기획안

### 1️⃣ 프로젝트 개요

| 항목        | 내용                                                             |
| --------- | -------------------------------------------------------------- |
| **목표**    | 국회의원들의 입법 활동과 출석률 등을 정량화하여, 시민이 직접 평가하고 설문에 참여할 수 있는 플랫폼 기능 개발 |
| **활용 목적** | 1. 여론 설문 자동 생성<br>2. 지역구 기반 정치참여 유도<br>3. 정치 데이터 기반 콘텐츠        |
| **타깃**    | 정치에 관심 있는 일반 시민 / 지역 주민 / 대학생 / 언론 관계자 등                       |

---

### 2️⃣ 기능 구성

#### 📌 A. 국회의원 활동 지수 DB 구축

| 지표 항목        | 설명               | 데이터 출처      | 활용 방법  |
| ------------ | ---------------- | ----------- | ------ |
| 대표 발의 수      | 의원이 직접 발의한 법안 수  | 국회 OPEN API | 랭킹/점수  |
| 공동 발의 수      | 공동 서명한 법안 수      | 국회 OPEN API | 협업력 판단 |
| 본회의 출석률      | 전체 본회의 대비 출석률    | 민간 DB/크롤링   | 성실도 점수 |
| 상임위 출석률      | 상임위원회 참석률        | 회의록 크롤링     | 성실도 점수 |
| 법안 통과율       | 대표발의 법안 중 통과된 비율 | 입법정보 시스템    | 실효성 평가 |
| 지역 활동지수 (선택) | SNS, 뉴스 언급량 등    | 크롤링 or 빅카인즈 | 향후 확장  |

#### 점수화 예시

```plaintext
총점 100점 기준
- 대표발의 수: 30점
- 본회의 출석률: 20점
- 법안 통과율: 20점
- 상임위 출석률: 10점
- 공동발의 수: 10점
- 기타 활동지수: 10점
```

---

#### 📌 B. UI / UX 기획 (웹앱)

1. **의원 카드형 뷰**

   * 의원 사진 + 이름 + 정당 + 지역구
   * 활동 점수 + 그래프형 지표
   * “이 의원이 발의한 법안 보기”
   * “이 의원의 활동, 어떻게 평가하세요?” → 설문 연결

2. **지역 기반 필터링**

   * 지역 선택 → 지역구 의원 리스트 & 성적표 보기
   * 해당 의원 법안 설문 리스트로 이동

3. **“일잘러 국회의원 랭킹”**

   * 전체 TOP10 랭킹 보드
   * 분야별(복지, 노동, 교육 등) 필터 가능
   * “지금 가장 활발한 의원은 누구?” 설문 자동 생성

### 3️⃣ 기술 구현 방식 (개요)

| 항목         | 내용                               |
| ---------- | -------------------------------- |
| **데이터 수집** | 국회 OPEN API 사용 + 크롤링             |
| **DB 설계**  | 의원 테이블, 활동 테이블, 법안 테이블, 출석 테이블 등 |
| **자동화 설문** | 활동이 높은 의원의 법안 → 설문 자동 발행         |
| **UI 구현**  | 카드형 / 테이블형 / 필터 뷰 디자인 적용         |
| **갱신 주기**  | 월 1회 or 회기 기준 자동 업데이트            |
