## 📝 Polli - "유명인 인기투표" 기능 기획서

---

### 1. 🎯 목적

* 사용자에게 재미와 몰입감을 주는 **유명인 기반 투표 콘텐츠** 제공
* 연예인/스포츠/정치인 등 인물 중심 콘텐츠로 **SNS 공유 및 참여율 증가**

---

### 2. 🧩 핵심 기능 요약

| 기능        | 설명                            |
| --------- | ----------------------------- |
| 인물 DB     | 위키데이터 기반 연예인/정치인/스포츠 인물 DB 구성 |
| 인물 검색/선택  | 투표 생성 시 인물 자동 검색 & 추가 가능      |
| 테마별 투표 생성 | 배틀형, 월드컵형, 순위형 등 다양한 포맷       |
| 유저 생성 가능  | 유저가 직접 유명인 추가, 투표 생성 가능       |
| 투표 참여     | 간단한 방식(1픽, 3픽, 랭킹 등)으로 투표 참여  |
| 결과 공유     | 실시간 순위, 지지율, SNS 공유 이미지 생성    |
| 랭킹 페이지    | 인물별 인기순위 제공 (일간/주간/월간)        |

---

### 3. 🖼️ 화면 구성 흐름 (UI/UX)

#### 📍 `/vote/celeb`

* 인기 테마 보기
* \[🔥 지금 투표중인 유명인 배틀] 목록
* 카테고리별 탭 (연예/스포츠/정치)

#### 📍 `/vote/create`

* \[유명인 투표 만들기] 탭 추가
* 테마 선택 → 인물 검색 및 추가 → 포맷 선택 → 생성 완료

#### 📍 `/celeb/:id`

* 인물 상세 페이지

  * 프로필 이미지, 간단 소개
  * 해당 인물이 등장한 모든 투표 목록
  * 누적 지지율, 최근 인기 투표 결과

#### 📍 `/rank/celeb`

* 실시간 인기 투표 순위

  * 카테고리별 필터
  * 월간/주간 랭킹

---

### 4. 🧠 투표 포맷 종류

| 포맷명         | 설명                 |
| ----------- | ------------------ |
| 1:1 배틀형     | 둘 중 누가 더 낫나 투표     |
| 1픽형         | 전체 중 1명만 고르는 인기 투표 |
| 3픽형         | 최대 3명까지 선택 가능      |
| 이상형 월드컵형    | 토너먼트 구조로 최애 선정     |
| 순위형 (1\~5위) | 사용자 개인 기준으로 랭킹 매김  |

---

### 5. 🤖 자동화 기능

* **위키데이터 API 연동**: 연예인/정치인/스포츠 선수 자동 등록
* **SNS 공유용 이미지 자동 생성**: 투표 결과 공유 → 유입 유도
* **투표 결과 그래프 자동 생성**: 막대, 파이, 랭킹 등

---

### 6. 📦 DB 설계 예시

#### `celeb_person`

| 필드          | 타입        | 설명                              |
| ----------- | --------- | ------------------------------- |
| id          | string    | person\_123                     |
| name        | string    | 아이유                             |
| image\_url  | string    | 프로필 이미지                         |
| category    | enum      | entertainment, sports, politics |
| tags        | string\[] | #여자가수 #Kpop 등                   |
| created\_by | user\_id  | 직접 추가한 유저                       |

#### `vote`

| 필드      | 설명                   |
| ------- | -------------------- |
| title   | 투표 제목                |
| type    | 배틀형, 순위형 등           |
| theme   | 예: 여름에 어울리는 스타       |
| options | celeb\_person\_id\[] |

---

### 7. 🎁 부가 기능 제안

* **투표 결과를 기반으로 하는 "이주의 인물"**
* **“투표로 보는 인물 트렌드 리포트” 메일 or SNS 포스팅 자동화**
* **스타 프로필 공유기능 (QR 포함)**
