완전 좋아. “이동식 장례의 장점”과 “지자체 실증특례(허가)의 공공기여”를 **명확히 측정**하면, 보고서에서 지자체가 좋아할 만한 **정책효과 지표**를 뽑아낼 수 있어.
아래는 기존 설문에 **추가할 블록**(문항), 그리고 **Polli용 JSON 확장안**, 마지막에 **지자체 보고서용 KPI 산식**까지 정리했어.

# A) 추가 블록 — 이동식 장례 장점(고객 관점)

> 리커트(1 전혀 아니다 ~ 5 매우 그렇다), 선택·자유서술 혼합

**A1. 접근성/편의**

* “장례 장소까지의 이동 부담이 크게 줄었습니다.” (1–5)
* “예약부터 진행까지 대기시간이 짧았습니다.” (1–5)
* “야간/주말 등 시간대 선택이 유연했습니다.” (1–5)

**A2. 정서·프라이버시**

* “이동식 서비스가 **사생활 보호**에 도움이 되었습니다.” (1–5)
* “반려가족과 **조용히 작별**할 시간이 충분했습니다.” (1–5)

**A3. 비용·투명성**

* “총 비용 안내가 **명확하고 예측 가능**했습니다.” (1–5)
* “이동/대기 등의 **추가 비용 고지**가 명확했습니다.” (1–5)

**A4. 환경·지역 영향(선택)**

* “장거리 이동이 줄어 **환경 부담(연료/시간)**이 감소했습니다.” (1–5)
* “주변 이웃·교통에 **불편을 최소화**했습니다.” (1–5)

**A5. 한 줄 장점(선택)**

* 자유서술 200자

# B) 추가 블록 — 지자체 실증특례/공공기여(고객 관점)

> 안내문 예시: “본 서비스는 지자체 협력 및 국가 실증특례 허가 하에 제공됩니다.”

**B1. 인식/신뢰**

* “지자체의 관리·허가 하에서 운영되어 **신뢰감**이 높았습니다.” (1–5)
* “지역 기준(위생/안전/소음 등)을 **준수**한다고 느꼈습니다.” (1–5)

**B2. 공공성과 편익**

* “실증특례 덕분에 **선택권**(이동식/고정식)이 확대되었습니다.” (1–5)
* “지역민(저소득/고령 등)에게 **접근성 향상**에 기여한다고 생각합니다.” (1–5)

**B3. 민원·소통**

* “사전/사후 **민원 대응 안내**가 충분했습니다.” (1–5)
* “지자체 협력으로 **책임 소재/연락 창구**가 분명했습니다.” (1–5)

**B4. 전반 공로 평가(한 줄)**

* “지자체가 이 서비스 도입에 기여한 점” (자유서술, 200자)

**B5. 지자체에 바라는 점(선택)**

* 더 넓은 운영시간 허용 / 추가 홍보 지원 / 취약계층 바우처 / 환경기준 가이드 명확화 / 기타(텍스트)

# D) 지자체 보고서용 KPI(자동 산출 지표)

* **접근성 개선지수(AAI)** = 평균( `mob_access`, `mob_time`, `mob_wait` ) × 20
* **프라이버시/정서지수(PEI)** = 평균( `mob_privacy` ) × 20
* **투명성지수(TI)** = 평균( `clarity`, `mob_fare` ) × 20
* **환경·지역영향지수(EI)** = 평균( `mob_env`, `mob_neighbor` ) × 20
* **공공신뢰지수(PTI)** = 평균( `mun_trust`, `mun_compliance` ) × 20
* **선택권확대지수(CEI)** = 평균( `mun_choice`, `mun_access` ) × 20
* **민원관리체감지수(CMI)** = 평균( `mun_complaint`, `mun_channel` ) × 20

> 1–5를 0–100척도로 환산(×20). 구/군별·월별 추세 그래프 + 상위 코멘트(긍정/개선 Top3) 자동 추출 추천.

# E) 운영 팁

* 민감도 고려: 모든 추가 블록은 **선택 응답 허용** 체크(미응답=결측).
* 문구 톤: “장점” 유도 질문이라도 **중립 표현** 유지(신뢰 확보).
* 보고서: “실증특례 덕분에 가능해진 공공 편익” 섹션을 **별도로** 구성해 지자체 로고와 함께 전달.

필요하면 캔버스에 **통합 JSON 파일**로 묶어서 올려줄게. 또한 Polli 대시보드에 위 KPI를 바로 그려주는 **차트 쿼리/뷰**(Supabase SQL + Recharts 컴포넌트)도 같이 만들어 줄 수 있어!
