## ✅ 국회 법률안 API 연동 + 설문 자동 생성 예시 (Node.js + OpenAI 기반)

```ts
// 1. 의안 목록 가져오기
import axios from "axios";

const API_KEY = "54424d7984cf4edd93b711fb868e22df";

async function fetchBills() {
  const url = "https://open.assembly.go.kr/portal/openapi/nzmimeepazxkubdpn";
  const res = await axios.get(url, {
    params: {
      KEY: API_KEY,
      Type: "json",
      pIndex: 1,
      pSize: 5,
      AGE: 21
    }
  });
  const bills = res.data.nzmimeepazxkubdpn.slice(1); // 0번은 metadata
  return bills.map(b => ({
    title: b.BILL_NAME,
    proposer: b.PROPOSER,
    coProposers: b.PUBL_PROPOSER,
    detailUrl: b.DETAIL_LINK
  }));
}
```

## 2. GPT로 설문지 생성 요청

```ts
import { Configuration, OpenAIApi } from "openai";

const openai = new OpenAIApi(
  new Configuration({ apiKey: process.env.OPENAI_API_KEY })
);

async function generateSurvey(billTitle: string) {
  const prompt = `
  "${billTitle}"라는 국회의원 발의 법률안이 있습니다.

  이에 대한 국민 여론을 알아보기 위한 설문지를 아래 형식으로 만들어주세요.

  Q. (질문)
  1. (선택지 1)
  2. (선택지 2)
  3. (선택지 3)
  4. (선택지 4)

  주제에 적합한 중립적이고 명확한 질문과 보기로 구성해주세요.
  `;

  const response = await openai.createChatCompletion({
    model: "gpt-4",
    messages: [{ role: "user", content: prompt }]
  });

  return response.data.choices[0].message?.content;
}
```

## 3. Polli 설문 포맷에 맞춰 저장

```ts
async function createPolliSurveyFromBill(bill) {
  const surveyText = await generateSurvey(bill.title);

  return {
    question: surveyText.split("\n")[0].replace("Q. ", ""),
    options: surveyText
      .split("\n")
      .slice(1, 5)
      .map(opt => opt.replace(/^\d\.\s/, "")),
    source: bill.detailUrl,
    proposer: bill.proposer,
    createdAt: new Date().toISOString()
  };
}
```

## ✅ 실행 예시

```ts
(async () => {
  const bills = await fetchBills();
  const firstBill = bills[0];
  const survey = await createPolliSurveyFromBill(firstBill);
  console.log(survey);
})();
```
