좋아, 지금부터 **프론트엔드에서 guest ID를 일관되게 생성하고 API 호출에 반영하는 전체 코드 흐름**을 알려줄게. 단계별로 설명도 붙여줄게.

---

## ✅ 1단계: guest ID 생성 및 localStorage 저장

```js
// src/hooks/useGuestAuth.js

import { useEffect, useState } from "react";

export function useGuestAuth() {
  const [guestId, setGuestId] = useState(null);

  useEffect(() => {
    let storedId = localStorage.getItem("guestAuthId");
    if (!storedId) {
      // 백엔드에 맞는 guestId 생성
      storedId = `guest_${Date.now()}_${btoa(navigator.userAgent.slice(0, 20))}`;
      localStorage.setItem("guestAuthId", storedId);
    }
    setGuestId(storedId);
  }, []);

  return guestId;
}
```

---

## ✅ 2단계: API 호출 시 guest ID 포함

```js
// src/utils/api.js

export async function apiRequest(url, options = {}) {
  const guestId = localStorage.getItem("guestAuthId");

  const res = await fetch(url, {
    ...options,
    headers: {
      ...(options.headers || {}),
      "Content-Type": "application/json",
      "X-Auth-ID": guestId, // 핵심: 모든 요청에 guestId 포함
    },
  });

  if (!res.ok) {
    const text = await res.text();
    throw new Error(`${res.status}: ${text}`);
  }

  return res.json();
}
```

---

## ✅ 3단계: App.js에서 인증 Hook 연결

```js
// src/App.js

import { useGuestAuth } from "./hooks/useGuestAuth";

function App() {
  const guestId = useGuestAuth();

  if (!guestId) return <div>로딩 중...</div>;

  return (
    <div>
      <h1>🎉 환영합니다! {guestId}</h1>
      {/* 실제 페이지 내용 */}
    </div>
  );
}

export default App;
```

---

## ✅ 4단계: 서버 (백엔드)에서는 `X-Auth-ID`만 받도록 설정

```ts
// 서버 미들웨어 예시 (Express.js 가정)

app.use((req, res, next) => {
  const authId = req.headers["x-auth-id"];
  if (!authId || !authId.startsWith("guest_")) {
    return res.status(400).json({ message: "인증 정보가 필요합니다." });
  }
  req.guestId = authId;
  next();
});
```
