## 📘 Polli 관리자 어드민 설계 프롬프트 (설문 통계 + 타겟 푸시 포함)

### 🔰 시스템 개요

Polli는 참여형 설문 기반 통계 플랫폼으로, 관리자(Admin)는 다음 기능들을 활용하여 설문 운영, 통계 분석, 타겟팅 캠페인, 어뷰징 방지를 총괄할 수 있습니다. 어드민은 데이터 기반 통계 기능 강화 및 연령·성별 기반 푸시/설문 타겟팅 기능을 포함합니다.

---

### ✅ 주요 기능 구성

#### 1. 📊 설문 통계 관리 (Survey Analytics)

* 설문별 상세 통계 보기 (응답 수, 유효 응답률, 선택지 분포)
* 성별 / 연령대 / 지역별 응답자 분포 차트
* 시간대별 응답 추이 그래프
* 댓글 요약 및 AI 통찰 제공
* 중복 응답 탐지 및 제외 설정
* 설문별 통계 CSV, Excel, PDF 다운로드

#### 2. 🧠 통합 통계 대시보드

* 총 설문 수 / 총 참여 수 / 월별 추이
* 참여율, 응답 시간 평균, 활동 사용자 수
* 인기 설문 랭킹 (참여수 / 좋아요수 기준)
* 필터링: 카테고리, 생성일, 타겟 여부

#### 3. 🎯 설문 타겟팅 기능

* 설문 생성 시 타겟팅 조건 설정 가능:

  * 성별 / 연령대 / 지역 / 최근 활동 조건
* 설정된 조건에 해당되는 사용자만 해당 설문 노출
* 타겟 설문 참여율 및 효과 분석 기능 포함

#### 4. 🔔 푸시 알림 설정 시스템

* 연령대, 성별, 지역, 활동 조건 기반 타겟 푸시 발송
* 알림 채널: 앱푸시 / 문자 / 카카오 알림톡 등 선택
* 발송 예약 기능 포함
* 푸시별 오픈률 / 클릭률 / 참여율 분석 리포트 제공

#### 5. 👮‍♀️ 어뷰징 탐지 및 필터링

* 중복 참여 의심 응답 자동 감지
* 빠른 응답시간, 동일 디바이스/IP 등 이상패턴 추적
* 의심 응답 통계에서 제외 처리 가능

#### 6. ⚙️ 기타 관리 기능

* 사용자 계정 조회, 정지, 포인트 조정
* 설문 숨김/삭제/수정 기능
* 공지사항, 이벤트 배너 노출 관리
* 관리자 권한 설정 (운영자, 통계담당 등)

---

### 🖥️ 어드민 UI 구조 (예시)

#### 사이드바 메뉴

```
[대시보드]
[설문 관리] ─ 개별 설문 통계, 수정, 삭제
[통계 분석] ─ 통합 설문 통계 리포트
[타겟 설문 설정]
[푸시 알림 관리]
[회원 관리]
[어뷰징 탐지]
[콘텐츠 관리]
```

#### 설문 상세 통계 페이지

* 요약 카드: 총 응답자 / 유효 응답률 / 좋아요 수
* 응답 분포 그래프 (연령, 성별, 지역)
* 시간대별 참여 추이
* 선택지별 응답 결과 (막대/도넛형)
* 댓글 요약 및 키워드 분석
* 중복응답 관리 (IP/디바이스 기반)

#### 타겟 설문 설정

```
[✓] 타겟 설문 설정
- 성별: 남성
- 연령대: 20~29세
- 지역: 서울, 경기
- 최근 7일간 활동자만 보기
```

#### 푸시 알림 설정

```
푸시 메시지: "20대 남성만 참여 가능! 설문 참여하고 200P 받자!"
대상: 20~29세 남성, 수도권
채널: 앱푸시 / 카카오 알림톡
발송일시: YYYY-MM-DD HH:mm
[예약 발송]
```

\| push\_id | message | target\_filter | sent\_at | opened | clicked | joined |

### 🛠️ 기술 스택 제안 (예시)

* **프론트엔드**: React + Recharts / Chart.js
* **백엔드**: Node.js or Python (FastAPI) + PostgreSQL
* **알림 푸시**: Firebase Cloud Messaging + 카카오 알림톡 API
* **로그 저장**: Redis or Kafka for 실시간 응답 기록
* **AI 요약**: GPT API를 활용한 댓글 요약 및 인사이트 생성
