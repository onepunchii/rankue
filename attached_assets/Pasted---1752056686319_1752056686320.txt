# 📰 **polli 앱 실시간 인기 뉴스 연동 투표 기능 구현 프롬프트**

『polli』 설문 플랫폼에서 다음과 같은 **실시간 뉴스 기반 투표 기능**을 반드시 구현해주세요.

---

## ✅ **기능 개요 (목적 및 개념)**

* 네이버 등 여러 주요 뉴스 매체의 실시간 인기 기사들을 API 또는 웹 크롤링으로 자동 수집합니다.
* 이 뉴스들을 플랫폼에 자동으로 등록해 사용자들이 기사 링크를 클릭하고 읽어본 후, 그 기사에 대한 **실시간 찬반 투표 또는 반응 투표**를 할 수 있도록 연결합니다.
* 실시간 사용자 의견 및 반응 데이터 확보를 통해 사용자 참여를 높이고 뉴스 이슈에 대한 빠른 반응 파악이 가능합니다.

---

## 📌 **기능 상세 구성 안내**

### 1️⃣ **뉴스 기사 데이터 소스 확보**

다음과 같은 방법 중 하나 또는 복수로 뉴스 기사 데이터를 확보합니다.

* **뉴스 API 활용 권장**:

  * **Naver Open API (네이버 뉴스 API)** 활용 권장

    * [네이버 뉴스 검색 API 공식 문서](https://developers.naver.com/docs/serviceapi/search/news/news.md)
  * 구글 뉴스 API, 뉴시스, 연합뉴스 API도 추가 고려 가능
  * API가 부족한 경우 **웹 크롤링 (Cheerio.js 또는 Puppeteer 활용)** 옵션 고려 가능

### 2️⃣ **기사 수집 및 자동 업데이트**

* 서버 측(Node.js + Express.js 기반)에서 일정 시간 간격(예: 매 5\~10분 간격)으로 최신 인기 기사 목록을 가져옵니다.
* 백엔드 DB에 뉴스 기사 목록을 저장합니다.

저장할 주요 데이터 예시:

| 필드명         | 설명          | 유형           | 예시값                                                                         |
| ----------- | ----------- | ------------ | --------------------------------------------------------------------------- |
| articleId   | 뉴스 기사 고유 ID | String(UUID) | "20230709-abc123"                                                           |
| title       | 기사 제목       | String       | "윤 대통령, 정상회담 참석..."                                                         |
| link        | 원본 기사 링크    | String(URL)  | "[https://n.news.naver.com/article/](https://n.news.naver.com/article/)..." |
| pubDate     | 기사 발행일      | DateTime     | "2023-07-09T11:00:00Z"                                                      |
| provider    | 뉴스 제공처      | String       | "네이버뉴스"                                                                     |
| category    | 기사 카테고리     | String       | "정치", "경제", "연예" 등                                                          |
| voteOptions | 투표 옵션 자동 생성 | Array        | \["공감", "비공감", "중립"]                                                        |

### 3️⃣ **기사별 투표 자동 생성 및 관리**

* 각 뉴스 기사 등록 시 자동으로 투표가 생성됩니다.
* 기본 투표 옵션 예시:

  * 찬성 vs 반대
  * 공감 vs 비공감 vs 중립
* 사용자는 기사 상세 페이지에서 바로 투표할 수 있습니다.

투표 데이터 관리 예시:

| 필드명       | 설명        | 유형           | 예시값                         |
| --------- | --------- | ------------ | --------------------------- |
| voteId    | 투표 고유 ID  | String(UUID) | "vote-20230709-xyz123"      |
| articleId | 연결된 기사 ID | String(UUID) | "20230709-abc123"           |
| votes     | 투표 현황 데이터 | Object       | {"공감":120,"비공감":40,"중립":20} |

### 4️⃣ **사용자 참여 및 투표**

* 사용자는 polli 플랫폼에서 원하는 기사 제목을 클릭하여 원본 기사로 이동 후 읽을 수 있습니다.
* 읽은 후 투표에 참여합니다.
* 사용자의 투표 내역은 블록체인(Klaytn 기반 스마트 컨트랙트)에 익명화하여 안전하게 기록 및 보관됩니다.
* 실시간 투표 현황과 결과를 즉시 사용자에게 제공합니다.

### 5️⃣ **실시간 투표 현황 및 결과 공유**

* 투표 결과는 실시간 집계되어 투표 페이지에 즉시 시각화하여 제공합니다.
* 그래프, 백분율, 투표자 수 등 직관적 형태로 표시하여 빠르게 파악 가능하도록 합니다.

## 🔧 **기술적 요구 사항**

* **백엔드**:

  * Node.js (Express.js), RESTful API 구성 필수
  * 뉴스 데이터 크롤링 자동화 작업 (Cron Jobs 혹은 Node Schedule)
  * 뉴스 데이터를 MongoDB 또는 PostgreSQL에 저장
  * 블록체인(Klaytn) 스마트 컨트랙트에 투표 기록 익명화 및 저장 관리

* **프론트엔드**:

  * React.js (Next.js 추천) 기반으로 구현
  * 뉴스 기사 리스트, 상세 페이지, 투표 인터페이스 구성
  * 투표 결과 실시간 업데이트 및 반응형(Responsive) UI 구성 필수

* **블록체인 연동**:

  * Klaytn 블록체인 연동 및 스마트 컨트랙트로 투표 결과 익명화 저장
  * Kaikas 지갑 로그인 지원

---

## 📲 **UI 및 UX 가이드**

* 사용자가 뉴스 기사 제목 클릭 시 **새 탭으로 원본 기사 링크 열기**(중요!)
* 투표 UI는 명확하고 직관적이며, 빠르게 투표 가능하도록 버튼 구성 (공감👍 vs 비공감👎 등)
* 실시간으로 투표 결과 업데이트(라이브 상태 반영)
