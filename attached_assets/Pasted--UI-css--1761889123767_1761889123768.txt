# 🎨 카카오톡 다크모드 UI 스펙 (심플 버전)

> 채팅 프로그램에 바로 적용 가능한 색상/레이아웃 정보

---

## 🎨 색상 팔레트

```css
/* ========== 배경 색상 ========== */
--bg-main: #1E1E1E;              /* 전체 배경 */
--bg-chat: #1E1E1E;              /* 채팅 영역 배경 */
--bg-header: #2C2C2E;            /* 헤더 배경 */
--bg-input: #3A3A3C;             /* 입력창 배경 */

/* ========== 말풍선 색상 ========== */
--bubble-other: #3A3A3C;         /* 상대방 말풍선 */
--bubble-mine: #FAE100;          /* 내 말풍선 */

/* ========== 텍스트 색상 ========== */
--text-primary: #FFFFFF;         /* 주요 텍스트 (일반 텍스트) */
--text-secondary: #AEAEB2;       /* 보조 텍스트 (시간, 정보) */
--text-tertiary: #8E8E93;        /* 비활성 텍스트 (플레이스홀더) */
--text-yellow-bubble: #3C1E1E;   /* 노란 말풍선 내부 텍스트 */

/* ========== 구분선 ========== */
--divider: #38383A;              /* 구분선 색상 */

/* ========== 강조 색상 ========== */
--accent-link: #4A90E2;          /* 링크 */
--accent-error: #FF3B30;         /* 오류/경고 */
--accent-success: #34C759;       /* 성공 */
```

---

## 📏 레이아웃 (간격 & 크기)

```css
/* ========== 말풍선 ========== */
--bubble-padding: 12px 16px;     /* 말풍선 내부 여백 */
--bubble-radius: 16px;           /* 말풍선 둥근 모서리 */
--bubble-max-width: 70%;         /* 말풍선 최대 너비 */
--bubble-margin-bottom: 8px;     /* 말풍선 간 세로 간격 */
--bubble-gap: 8px;               /* 프로필-말풍선 가로 간격 */

/* ========== 채팅 영역 ========== */
--chat-padding: 16px;            /* 채팅 영역 좌우 여백 */
--message-group-gap: 12px;       /* 다른 사람 메시지 그룹 간격 */

/* ========== 입력창 ========== */
--input-height: 48px;            /* 입력창 높이 */
--input-padding: 12px 16px;      /* 입력창 내부 여백 */
--input-radius: 24px;            /* 입력창 둥근 모서리 */
--input-bar-padding: 12px;       /* 입력 바 전체 여백 */

/* ========== 헤더 ========== */
--header-height: 56px;           /* 헤더 높이 */
--header-padding: 0 16px;        /* 헤더 좌우 여백 */

/* ========== 프로필 이미지 ========== */
--profile-size: 40px;            /* 프로필 이미지 크기 */
```

## 📐 정렬 및 구조

```
┌─────────────────────────────────────┐
│  HEADER (56px)                      │  ← bg-header, padding: 0 16px
├─────────────────────────────────────┤
│                                     │
│  CHAT AREA                          │  ← bg-chat, padding: 16px
│                                     │
│  ┌──────────────────────────┐      │  ← 상대방 메시지 (왼쪽 정렬)
│  │ [프로필] [말풍선] [시간]  │      │
│  └──────────────────────────┘      │
│                                     │
│       ┌──────────────────────┐     │  ← 내 메시지 (오른쪽 정렬)
│       │ [시간] [말풍선]       │     │
│       └──────────────────────┘     │
│                                     │
├─────────────────────────────────────┤
│  INPUT BAR (padding: 12px)          │  ← bg-header
│  [   입력창 (48px)   ] [전송버튼]   │
└─────────────────────────────────────┘
```

---

## 💬 말풍선 정렬 규칙

### 상대방 메시지 (왼쪽 정렬)
```
[프로필]  [말풍선───────]  [시간]
 (40px)    (max 70%)      (11px)
  └─8px→   ←────8px────→
```

### 내 메시지 (오른쪽 정렬)
```
        [시간]  [말풍선───────]
        (11px)    (max 70%)
     ←──8px──→
```

## 🎯 적용 예시 (순수 CSS)

```css
/* 전체 레이아웃 */
body {
  background: #1E1E1E;
  color: #FFFFFF;
  font-family: -apple-system, BlinkMacSystemFont, 'Apple SD Gothic Neo', sans-serif;
  font-size: 15px;
  line-height: 1.5;
  margin: 0;
  padding: 0;
}

/* 헤더 */
.header {
  background: #2C2C2E;
  height: 56px;
  padding: 0 16px;
  display: flex;
  align-items: center;
  border-bottom: 1px solid #38383A;
}

/* 채팅 영역 */
.chat-area {
  background: #1E1E1E;
  padding: 16px;
  overflow-y: auto;
}

/* 상대방 메시지 컨테이너 */
.message-other {
  display: flex;
  gap: 8px;
  margin-bottom: 8px;
  align-items: flex-end;
}

/* 내 메시지 컨테이너 */
.message-mine {
  display: flex;
  gap: 8px;
  margin-bottom: 8px;
  align-items: flex-end;
  flex-direction: row-reverse;
  justify-content: flex-start;
}

/* 상대방 말풍선 */
.bubble-other {
  background: #3A3A3C;
  color: #FFFFFF;
  padding: 12px 16px;
  border-radius: 16px;
  max-width: 70%;
  word-wrap: break-word;
}

/* 내 말풍선 */
.bubble-mine {
  background: #FAE100;
  color: #3C1E1E;
  padding: 12px 16px;
  border-radius: 16px;
  max-width: 70%;
  word-wrap: break-word;
}

/* 시간 표시 */
.message-time {
  color: #8E8E93;
  font-size: 11px;
  align-self: flex-end;
  white-space: nowrap;
}

/* 프로필 이미지 */
.profile-image {
  width: 40px;
  height: 40px;
  border-radius: 50%;
  flex-shrink: 0;
}

/* 입력 바 */
.input-bar {
  background: #2C2C2E;
  padding: 12px;
  border-top: 1px solid #38383A;
  display: flex;
  gap: 8px;
}

/* 입력창 */
.input-field {
  background: #3A3A3C;
  color: #FFFFFF;
  border: none;
  border-radius: 24px;
  padding: 12px 16px;
  flex: 1;
  height: 48px;
  font-size: 15px;
}

.input-field::placeholder {
  color: #8E8E93;
}

/* 전송 버튼 */
.send-button {
  background: #FAE100;
  color: #3C1E1E;
  border: none;
  border-radius: 50%;
  width: 48px;
  height: 48px;
  cursor: pointer;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

## 📱 HTML 구조 예시

```html
<!DOCTYPE html>
<html>
<body>
  <!-- 헤더 -->
  <div class="header">
    <h1 style="font-size: 17px; font-weight: 600; margin: 0;">채팅방 이름</h1>
  </div>

  <!-- 채팅 영역 -->
  <div class="chat-area">
    
    <!-- 상대방 메시지 -->
    <div class="message-other">
      <img class="profile-image" src="profile.jpg" alt="프로필">
      <div class="bubble-other">
        안녕하세요! 반갑습니다.
      </div>
      <span class="message-time">오후 2:34</span>
    </div>

    <!-- 내 메시지 -->
    <div class="message-mine">
      <span class="message-time">오후 2:35</span>
      <div class="bubble-mine">
        네, 안녕하세요!
      </div>
    </div>

  </div>

  <!-- 입력 바 -->
  <div class="input-bar">
    <input type="text" class="input-field" placeholder="메시지를 입력하세요...">
    <button class="send-button">
      ➤
    </button>
  </div>
</body>
</html>
```
