# 당구 온라인게임 — 당구대 테마 · 등급별 큐대 기획서

- 상태: **보류(킵)** — 지금은 만들지 않는다. 아래 '다시 꺼내는 때'가 오면 이 문서에서 시작한다.
- 쓴 날: 2026-10-12
- 오너 말(2026-10-12): "이건 일단 킵하자. 나중에 회원 수 많아지고 경기 추가가 되면 그때 적용하는 걸로. 일단 B·C 좋네. 나중에 온라인 대회 열릴 때 그때 다시 기획하기로 하고, 당구 큐 또한 등급을 세분화해서 큐를 만들어서 제공하는 것까지 기획서에 담아 줘."

## 1. 한눈에

| 무엇 | 정해진 것 | 남은 것 |
|---|---|---|
| 당구대 테마 | 시안 4종 가운데 **B 클래식 그린 · C 미드나잇**이 좋다 | 언제 넣을지(온라인 대회 때 다시 기획) |
| 등급별 큐대 | 등급을 세분화해 큐대를 만들어 준다 | 등급 기준 · 단계 수 · 얻는 방법 · 성능 차이 여부(7장) |
| 큐대가 테두리에 파묻히던 것 | **고쳐서 배포함**(2026-10-12) — 큐 뒤쪽을 들어 레일과 다른 공을 넘어간다 | 없음 |

## 2. 다시 꺼내는 때

오너가 정한 조건은 둘이다.

1. **온라인 대회를 열 때** — 대회 기획과 같이 다시 본다. 대회 기획은 같은 날 따로 썼다: [월대회 · 티어 배지 · 장식장](online-game-monthly-tournament-badges.md). 우승 큐대 같은 보상은 그 대회가 자리를 잡은 뒤에 여기서 꺼낸다.
2. **회원 수가 늘고 경기가 추가될 때.**

참고로 지금 규모(2026-10-12, 운영 자료):

- 전체 회원 219명. 온라인게임을 최근 30일에 혼자 친 사람 27명.
- 온라인 대전 사다리: 3쿠션 9명(아이언 1 · 브론즈 5 · 실버 1 · 배치 중 2), 4구 5명(브론즈 3 · 배치 중 2). 골드 위로는 아직 아무도 없다.
- 끝난 대전은 한 주에 27~68판, 치는 사람은 한 주에 6~10명. 누적 202판.

이 규모에서는 등급을 잘게 나눠도 칸마다 사람이 없다. 숫자로 된 기준이 필요하면 **한 주에 대전을 치는 사람이 30명 안팎**이 되는 때를 제안한다(제안일 뿐, 정해진 것 아님).

## 3. 오늘 해 본 것 — 시안에서 알게 된 사실

OpenRouter 의 이미지 모델로 재료(테두리 나무 · 큐대 무늬 · 대전방 배경)를 만들고, 로컬에서 **실제 게임 화면에 임시로 입혀** 찍었다. 운영에는 아무것도 넣지 않았다.

- 시안 그림: [위에서 보기](online-game-themes-and-cues/sheets/sheet-top.jpg) · [3D 시점(치는 화면)](online-game-themes-and-cues/sheets/sheet-3d.jpg) · [만든 재료](online-game-themes-and-cues/sheets/sheet-materials.jpg)
- 재료 원본(JPEG 사본): `online-game-themes-and-cues/materials/` — `b-*`, `c-*` 가 고른 두 테마, `a-*`, `d-*` 는 참고용.

| 시안 | 천 | 테두리 | 배경 | 판정 |
|---|---|---|---|---|
| A 대회장 블루 | 파랑 | 유광 마호가니 | 어두운 대회장 조명 | 지금 모습과 차이가 작다. 유광 나무가 조명에 하얗게 떠서 색을 다시 맞춰야 한다 |
| **B 클래식 그린** | 초록 | 월넛 | 따뜻한 당구장 조명 | **오너 선택** |
| **C 미드나잇** | 차콜 | 무광 블랙 | 네온 라운지 | **오너 선택** |
| D 민트 메이플 | 청록 | 밝은 메이플 | 밝은 스튜디오 | 밝은 배경이 어두운 게임 화면과 부딪힌다 |

입혀 보고 알게 된 것(만들 때 그대로 전제로 쓴다):

1. **치는 화면(3D 시점)은 거의 다 천이다.** 테두리는 맨 위에 실오라기만 보이고 배경은 안 보인다. 이 화면에서 테마는 사실상 '천 색'이다.
2. **위에서 보기에서는 테두리 나무와 배경이 잘 보인다.** 다만 배경이 게임 영역까지만 그려져 오른쪽 단추 줄과 경계선이 생긴다 — 정식 구현 때 고칠 것.
3. **천은 그림을 만들 필요가 없다.** 만들어 봐도 단색에 가깝다. 색만 정하고 지금처럼 코드로 그린다(`client/src/sim/render/felt.ts`).
4. **큐대 무늬는 게임 안에서 안 보인다.** 화면에서 큐대가 너무 가늘다. 게임 안에서는 색 조합만 의미가 있고, 무늬는 따로 크게 보여 주는 자리(5.5)가 있어야 산다.
5. **천 색에는 제약이 있다.** 공이 흰 · 노랑 · 빨강이라 빨강 · 노랑 · 밝은 계열 천은 공이 안 보인다(버건디를 뺀 이유).
6. 지금은 대대 = 파랑, 중대 = 초록으로 당구대마다 천 색이 정해져 있다(2026-09-18 오너 결정). 테마를 넣으면 이 규칙과 어느 쪽이 이기는지 정해야 한다.

그림 만들기 실측: OpenAI 이미지 모델(`openai/gpt-5-image-mini`)로 장당 약 60원, 정사각 1024px. 구글 Gemini 이미지 모델은 밋밋한 질감 그림을 거절했다. 이번 시안에 쓴 돈은 18번 호출 0.76달러(약 1,050원). 프롬프트와 비용은 `online-game-themes-and-cues/tools/prompts-ledger.jsonl`.

## 4. 당구대 테마

### 4.1 무엇을 바꾸나

테마 하나 = **천 색 + 테두리 나무 질감 + 대전방 배경 + 기본 큐대 색**.

| 테마 | 천(가운데 → 가장자리) | 테두리 | 배경 | 비고 |
|---|---|---|---|---|
| 기본(지금 그대로) | 대대 파랑 · 중대 초록 | 갈색 단색 | 없음(어두운 바탕) | 아무것도 안 고르면 이것 |
| B 클래식 그린 | `#1A7A48` → `#0B5D3B` | 월넛(`b-wood`) | 당구장 조명(`b-room`) | |
| C 미드나잇 | `#4A5261` → `#2A2F3A` | 무광 블랙(`c-wood`) | 네온 라운지(`c-room`) | |

### 4.2 규칙

- **내 화면에만 적용한다.** 상대는 자기 테마로 본다(경기 내용은 같다).
- **기본값은 지금 모습 그대로.** 고르지 않은 사람에게는 아무것도 달라지지 않는다.
- 두 화면 모두 지원한다: 위에서 보기 · 3D 시점(둘 다 3D 엔진이 그린다). 3D 를 못 쓰는 기기의 2D 화면에도 같은 색 · 무늬를 입힌다.
- 그림은 줄여서 넣는다(원본 PNG 1~2MB → webp 100KB 안팎). 배경은 흐린 그림이라 작게 줄여도 된다.
- 공이 잘 보이는지를 테마마다 확인한다(흰 · 노랑 · 빨강 공과 조준선).

### 4.3 온라인 대회와 묶을 수 있는 것(대회 기획 때 정한다)

- 대회 경기에는 대회 전용 모습(예: A 대회장 블루를 다듬어서)을 모두에게 같게 입히는 안.
- 대회 참가 · 입상 보상으로 테마를 주는 안. 아니면 테마는 누구나 고르게 두고 보상은 큐대로만 주는 안.

### 4.4 만들 일

| 일 | 크기 |
|---|---|
| 테마 정의(공용 모듈)와 설정 저장(기기 또는 계정) | 작음 |
| 3D 엔진: 테두리 · 받침 · 몸체에 나무 질감, 배경, 큐대 색. 질감이 늦게 불러와져도 다시 그리기 | 중간 |
| 2D 화면: 테두리 무늬 · 바탕 · 큐대 색 | 작음 |
| 배경이 단추 줄까지 이어지게(경계선 없애기), 유광 나무 색 맞추기 | 작음 |
| 설정 화면의 테마 고르기(미리보기 포함) | 중간 |
| 그림 줄이기 · 싣기 | 작음 |

시안 때 쓴 임시 손질이 `online-game-themes-and-cues/tools/theme-demo.diff` 에 있다. `window.__simTheme` 으로 테마를 넣는 시험용이고 그대로 쓸 코드는 아니다 — 어디를 건드려야 하는지 보는 용도다. 그 뒤로 엔진 파일이 바뀌어(큐대 올림각) 그대로는 안 붙을 수 있다.

## 5. 등급별 큐대

### 5.1 목적

- 사다리를 오르는 보람을 눈에 보이게 한다. 지금은 등급 이름표뿐이다.
- 온라인 대회의 보상거리를 만든다(우승 큐대처럼 그 대회에서만 얻는 것).

### 5.2 원칙(제안 — 다시 꺼낼 때 오너가 확정한다)

1. **성능 차이를 두지 않는다. 겉모습만 다르다.** 대전은 실력(Elo 레이팅)으로 겨루는 사다리다. 큐대에 힘 · 회전 · 조준선 차이를 두면 등급이 높은 사람이 더 유리해져 사다리가 무너진다.
2. **돈으로 팔지 않고, 뽑기로 주지 않는다(첫 버전).** 얻는 길은 실력과 참여뿐이다. 유료 판매나 확률형으로 가려면 법 · 스토어 정책을 먼저 확인해야 한다(8장).
3. **한 번 얻은 큐대는 잃지 않는다.** 등급이 내려가도 보관함에 남는다. 지금 등급의 표시는 이름표가 한다.
4. 내기 · 금액과 엮지 않는다.

### 5.3 등급 체계(안)

지금 온라인 대전 사다리는 일곱 등급이다(`shared/sim/rank.ts` — Elo 1000 시작, 3판 배치 뒤 등급). 여기에 **등급마다 세 단계**를 둬서 세분화한다. 마스터는 단계 없이 하나.

| 등급 | 레이팅 | 단계 | 큐대 모습(안) |
|---|---|---|---|
| 아이언 | 950 미만 | 없음 | 장식 없는 물푸레나무, 회갈색 — 시작 큐대 |
| 브론즈 | 950~ | III · II · I | 밝은 단풍나무 + 구리색 링 |
| 실버 | 1050~ | III · II · I | 단풍나무 상대 + 짙은 하대 + 은색 링 |
| 골드 | 1150~ | III · II · I | 장미목 하대 + 금색 링 + 네 갈래 검 무늬 |
| 플래티넘 | 1250~ | III · II · I | 흑단 하대 + 백금색 링 + 흰 마름모 상감 |
| 다이아 | 1350~ | III · II · I | 흑단 + 푸른 검 무늬 + 마름모 상감 |
| 마스터 | 1450~ | 없음 | 시즌마다 다른 전용 디자인 |

- 단계는 **링의 수**(1 · 2 · 3개)로 나타낸다. 게임 안에서도 보이는 유일한 장식이 링이라서다.
- 등급 큐대는 모두 19자루(아이언 1 + 다섯 등급 × 3 + 마스터 1).
- 단계의 폭은 등급 폭 100점을 셋으로 나눈 33 · 33 · 34점.
- 3쿠션과 4구는 사다리가 따로다. 큐대도 종목마다 따로 줄지, 둘 중 높은 쪽으로 하나만 줄지는 정해야 한다(7장).

### 5.4 등급 밖의 큐대

| 종류 | 얻는 길 | 예 |
|---|---|---|
| 기본 큐대 | 처음부터 | 색 서너 가지 중 고르기 |
| 대회 큐대 | 온라인 대회 우승 · 준우승 · 4강 · 참가 | 대회 이름과 회차를 새긴 것 — 그 대회에서만 |
| 시즌 큐대 | 시즌이 끝날 때 도달한 최고 등급 | 시즌 번호가 들어간 것(시즌제를 한다면) |
| 업적 큐대 | 기록 달성 | 하이런, 100승, 연승, 이번 주 과제 완주 |

### 5.5 어디에 보이나

시안에서 확인했듯 게임 안의 큐대는 가늘어서 무늬가 안 보인다. 그래서 크게 보여 주는 자리가 같이 있어야 큐대가 값어치를 가진다.

- **큐대 보관함** — 가진 큐대와 아직 못 얻은 큐대(얻는 조건과 함께), 가까이 본 그림.
- **대전 시작 화면** — 양쪽 선수의 등급 · 큐대.
- **승리 화면**, 승급했을 때 "새 큐대를 얻었습니다".
- **랭킹 · 프로필**의 작은 큐대 표시.
- **게임 안** — 큐대 색 조합과 링(몇 줄). 상대의 큐대도 그 사람 것으로 보인다(대전에서 상대 큐대를 이미 그린다).

### 5.6 큐대 하나를 이루는 것

- 게임 안 모습: 상대 · 하대 · 페룰 · 팁의 색(지금 네 토막으로 그린다) + 링(얇은 토막을 더한다).
- 가까이 본 그림: 이미지 모델로 만들어 고른다. 한 장에 60원쯤이라 30자루를 만들어도 몇천 원이다. 한 벌로 보이게 같은 화풍 · 같은 구도로 맞추는 손질이 더 큰 일이다.
- 그림 속에 실제 브랜드 · 로고 · 글자를 넣지 않는다.

### 5.7 자료 구조(안)

- 큐대 목록은 코드에 둔다(공용 모듈): id · 종류(등급 · 대회 · 시즌 · 업적 · 기본) · 등급과 단계 · 색 · 링 · 그림 주소 · 얻는 조건.
- 회원이 가진 큐대: 표 하나(회원 id · 큐대 id · 얻은 날 · 얻은 까닭). 지우지 않는다.
- 지금 끼운 큐대: 회원마다 하나(종목별로 둘지는 5.3 과 같이 정한다).
- 주는 시점: 대전이 끝나 레이팅이 바뀔 때 서버가 준다. 같은 큐대를 두 번 주지 않는다.
- 대전 중 상대에게 내 큐대를 보이려면 대전 정보에 끼운 큐대 id 를 싣는다.

### 5.8 만들 일

| 일 | 크기 |
|---|---|
| 등급 단계(III · II · I) 계산과 표시 — 큐대와 무관하게 먼저 넣을 수 있다 | 작음 |
| 큐대 목록 모듈 · 가진 큐대 표 · 주는 로직(승급 · 업적) | 중간 |
| 게임 안: 큐대 색 · 링을 끼운 큐대대로(내 것 · 상대 것) | 중간 |
| 큐대 보관함 화면, 승급 알림 | 중간 |
| 대전 시작 · 승리 화면, 랭킹 · 프로필 표시 | 중간 |
| 큐대 그림 만들기 · 고르기 · 줄이기(19자루 + 특별 큐대) | 중간 |
| 대회 · 시즌 큐대 — 대회 기획에 딸려 온다 | 대회 기획에서 |

## 6. 순서(다시 꺼냈을 때의 제안)

1. **등급 단계 표시** — 사람이 늘어 등급 칸이 채워지기 시작하면 이것부터. 큐대 없이도 뜻이 있다.
2. **당구대 테마 B · C** — 고르기만 하면 되는 가벼운 기능. 대회 전에 먼저 내도 된다.
3. **등급 큐대 + 보관함** — 사다리 인원이 받쳐 줄 때.
4. **대회 큐대 · 대회 전용 모습** — 온라인 대회 기획과 같이.

## 7. 그때 오너가 정할 것

1. 큐대에 성능 차이를 두지 않는 것으로 갈지(이 문서의 제안은 '두지 않는다').
2. '등급'을 온라인 대전 등급으로 볼지, 실전 기록(RP · 에버리지)으로 볼지(이 문서는 온라인 대전 등급으로 썼다).
3. 세분화 정도 — 등급마다 세 단계가 맞는지.
4. 3쿠션 · 4구 큐대를 따로 줄지 하나로 줄지.
5. 등급이 내려가도 큐대를 그대로 둘지(제안은 '둔다').
6. 테마는 누구나 고르게 둘지, 보상으로 줄지.
7. 대대 파랑 · 중대 초록 규칙과 테마 가운데 어느 쪽이 이기는지.
8. 시즌제를 할지.
9. 나중에라도 팔 생각이 있는지 — 있다면 8장을 먼저 확인한다.

## 8. 확인이 필요한 것(지금 결론 내리지 않음)

- 큐대 · 테마를 **유료로 팔거나 뽑기로 주면** 게임 아이템 관련 법(확률형 아이템 정보 공개 등)과 스토어 인앱결제 정책이 걸린다. 첫 버전을 '무료 · 실력과 참여로만'으로 잡은 이유다. 팔기로 하면 그때 따로 조사한다.
- 큐대 · 배경 그림은 AI 로 만든 것이다. 실제 장소 · 브랜드 · 사람처럼 보이지 않게 하고, 실사처럼 보이는 그림의 표시 의무가 있는지는 넣기 전에 확인한다.

## 9. 같이 고친 것 — 큐대가 테두리에 파묻히던 문제(2026-10-12 배포)

오너: "온라인게임에서 큐가 당구 테두리 안으로 들어간 모습이 보이는데 이건 꼬이지 않게 잘 해 줘."

- 원인: 3D 엔진이 큐대를 수구 높이(31mm)에 수평으로 눕혀 그렸는데 레일 윗면이 그보다 높다(45mm). 큐대가 레일 위를 지나는 자리에서 나무 속에 파묻혔다. 위에서 보기에서는 레일이 큐대를 덮었고, 3D 시점에서는 큐대가 레일을 뚫었다. 큐대 길 위에 다른 공이 있을 때도 그 공을 꿰뚫었다.
- 고친 것: 실제로 치는 사람이 하듯 **수구 중심을 축으로 큐 뒤쪽을 든다**. 레일을 넘기 시작하는 자리와 길 위의 공마다 넘어야 할 높이를 셈해 가장 큰 각을 쓴다(상한 약 34도). 넘을 것이 없으면 수평 그대로다. 그리기에만 쓰고 샷의 물리에는 영향이 없다.
- 코드: `client/src/sim/render/threeMath.ts` 의 `cueElevation`, 시험 `cueElevation.test.ts`.
- 큐대 스킨을 만들 때 이 올림각 위에 그대로 얹으면 된다.
