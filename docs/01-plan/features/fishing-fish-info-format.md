# 어종 정보 — 받는 형식

> 2026-10-14 오너: "내가 어종정보랑 정보는 줄 테니 니가 설계만 잘해 놔."
> 틀은 `shared/fishingFishInfo.ts`, 화면은 `client/src/fishing/FishSheet.tsx`(어종 한 장).
> **이 문서에 적힌 예시의 글은 자리 글이다 — 어종의 사실이 아니다.**

## 어디에 보이는가

어종 한 장은 어탁첩의 칸 · 홈의 대표 기록어 · 어탁 벽 · 지도의 "○○ 한 장"을 누르면 열린다. 위에서부터:

1. 종이 위의 어탁 · 이름 · **다른 이름** · **한 줄 소개** · 낙관의 사다리(몇 짜부터 무슨 낙관인가)
2. 내 기록 — 가장 큰 한 마리의 사진 · 남긴 사진들 · 최근 줄
3. 오늘 좋은 곳 — 국립해양조사원 바다낚시지수(지수가 매겨지는 어종만)
4. 위판장 — 지난 이레의 경매 건수(해양수산부 자료에 있는 어종만)
5. **어종 이야기** — 제철(열두 달의 띠) · 사는 곳 · 낚시 방법 · 미끼 · 물때·시간 · 맛 · 요령 · 금어기·금지체장 · 자료의 출처

굵게 적은 것이 받은 자료로 채워지는 칸이다. **채워진 칸만 그려진다** — 비워 두면 그 줄이 없을 뿐 화면은 멀쩡하다. 한 어종에 한두 칸만 와도 된다.

## 칸

| 칸 | 이름 | 꼴 | 길이 | 예시(자리 글) |
|---|---|---|---|---|
| 다른 이름 | `aka` | 여럿(쉼표 · 가운뎃점으로 나눔) | 8개 · 하나에 16자 | 사투리, 별명, 표준명 |
| 한 줄 소개 | `intro` | 글 | 120자 | 한두 문장 |
| 제철 | `season` | 달의 숫자(1~12) 여럿 | — | 10, 11, 12, 1, 2 |
| 사는 곳 | `habitat` | 글 | 120자 | 갯바위 · 방파제 · 모래 바닥 같은 것 |
| 낚시 방법 | `methods` | 여럿 | 6개 · 하나에 24자 | 방법 이름들 |
| 미끼 | `bait` | 여럿 | 8개 · 하나에 20자 | 미끼 · 루어 이름들 |
| 물때 · 시간 | `timing` | 글 | 120자 | 한마디 |
| 맛 | `taste` | 글 | 120자 | 한마디 |
| 요령 | `tips` | 여럿(줄마다 하나) | 5줄 · 한 줄 100자 | 줄마다 한 가지 |
| 금어기 · 금지체장 | `ban` | 아래 참고 | | |
| 자료의 출처 | `sources` | 여럿 | 6개 · 하나에 80자 | 책 · 기관 · 사이트의 이름 |

길이를 넘으면 잘린다. 모르는 칸(가격 · 별점 같은 것)은 버려진다 — 필요하면 칸을 새로 만든다.

### 금어기 · 금지체장(`ban`)

| 칸 | 이름 | 꼴 |
|---|---|---|
| 금어기 | `period` | 글(40자) — 예: `○.○ ~ ○.○` |
| 금지체장 | `minCm` | 숫자(cm) |
| 덧붙임 | `note` | 글(100자) — 해역 예외 같은 것 |
| **출처** | `source` | 글(80자) — **법령 · 고시의 이름과 기준일. 꼭 있어야 한다** |

법이 정하고 해마다 바뀔 수 있는 값이라 **출처가 없으면 통째로 싣지 않는다**(코드가 버린다). 금어기나 금지체장 둘 중 하나만 있어도 된다.

## 보내는 꼴

편한 것으로 보내면 된다 — 내가 틀에 맞춰 넣는다.

- **표**(엑셀 · 구글 시트 · CSV): 첫 줄에 `어종, 다른 이름, 한 줄 소개, 제철, 사는 곳, 낚시 방법, 미끼, 물때·시간, 맛, 요령, 금어기, 금지체장, 금어기 덧붙임, 금어기 출처, 출처`. 한 줄에 한 어종. 여럿인 칸은 쉼표나 가운뎃점으로, 요령은 줄바꿈으로.
- **글**: 어종마다 한 덩이. 칸의 이름을 앞에 적어 주면 된다(`제철: 10~2월`).
- **JSON**: 아래 꼴.

```json
{
  "gamseongdom": {
    "aka": ["(다른 이름)", "(별명)"],
    "intro": "(한 줄 소개)",
    "season": [10, 11, 12, 1, 2],
    "habitat": "(사는 곳)",
    "methods": ["(방법 하나)", "(방법 둘)"],
    "bait": ["(미끼 하나)", "(미끼 둘)"],
    "timing": "(물때 · 시간대 한마디)",
    "taste": "(맛 · 먹는 법)",
    "tips": ["(요령 한 줄)", "(둘째 줄)"],
    "ban": { "period": "○.○ ~ ○.○", "minCm": 0, "note": "(덧붙임)", "source": "(법령 이름 · 기준일)" },
    "sources": ["(자료의 출처)"]
  }
}
```

어종은 이름으로 적어도 된다(감성돔). 아래 표의 이름과 꼭 같아야 그 어종의 칸에 들어간다.

### 어종을 더 넣고 싶으면

목록에 없는 어종(학꽁치 · 전갱이 · 한치 …)의 정보를 주면 어종부터 넣는다. 그때 같이 알려 줄 것:

- 이름(낚시꾼이 부르는 이름) · 바다/민물
- 무엇으로 겨루는가(길이 · 마릿수 · 무게 · 굵기)와 **낙관의 단계**(예: 3짜 30cm · 4짜 40cm) — 모르면 길이 10cm 단위로 잡아 두고 나중에 고친다

어탁 그림은 내가 같은 손(먹 어탁)으로 한 장 찍는다. 넣은 뒤에는 이 표에도 한 줄을 더한다(시험이 빠진 것을 잡는다).

## 지키는 것

- **받은 자료만 싣는다.** 비어 있는 칸을 내가 지어 채우지 않는다.
- 금어기 · 금지체장은 출처와 같이만.
- "잘 낚인다" · "나가도 된다" 같은 말은 받은 글에 있어도 화면의 다른 자료(낚시지수 · 위판)와 섞어 쓰지 않는다 — 그 구역들은 기관의 값이라고 따로 적혀 있다.
- 남의 글을 그대로 옮긴 것이면 출처 칸에 적어 준다(화면 맨 아래에 "자료: …"로 나온다).
