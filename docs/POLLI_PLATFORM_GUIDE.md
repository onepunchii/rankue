## 1. 플랫폼 개요

### 1.1 폴리란?
폴리(Polli)는 블록체인 기반의 모바일 우선 설문 플랫폼으로, 참여하기 쉽고 신뢰할 수 있는 공공 여론 수집 시스템입니다.

### 1.2 핵심 가치
- **참여 용이성**: 간편한 인증과 직관적인 UI
- **익명성 보장**: Deep Poll 카테고리를 통한 익명 설문 지원
- **보상 시스템**: 참여에 대한 포인트, 경험치, 로또 티켓 보상
- **신뢰성**: 검증된 사용자 기반의 데이터 수집

### 1.3 사용자 유형
| 유형 | 권한 | 설명 |
|------|------|------|
| 게스트 | 읽기 전용 | 로또 티켓 0장, 포인트 적립 불가 |
| 회원 | 전체 기능 | 설문 참여, 포인트 적립, 로또 참여 가능 |
| 관리자 | 관리 권한 | 대시보드, 설문 관리, 회원 관리 |

## 2. 회원 시스템

### 2.1 인증 아키텍처
폴리는 JWT 기반 2계층 인증 시스템을 사용합니다.

#### 인증 흐름
```
[사용자] → [로그인/회원가입] → [JWT 토큰 발급] → [쿠키 저장]
                                    ↓
                            [30일 유효기간]
```

### 2.2 회원가입 요구사항
| 필드 | 필수 여부 | 규칙 |
|------|----------|------|
| 이메일 | 필수 | 중복 불가, 유효한 형식 |
| 비밀번호 | 필수 | 6자리 숫자 |
| 이름 | 필수 | - |
| 휴대폰 | 필수 | 01X-XXXX-XXXX 형식 |
| 연령대 | 필수 | 10대 ~ 70대 이상 |
| 성별 | 필수 | 남성/여성/기타 |
| 지역 | 필수 | 시/도 선택 |

### 2.3 회원가입 보너스
- **로또 티켓 5장** 자동 지급
- **레벨 1** 시작
- **닉네임** 자동 생성 (예: "용감한독수리123")

### 2.4 로그인 보안 정책
| 항목 | 정책 |
|------|------|
| 실패 허용 횟수 | 5회 |
| 계정 잠금 시간 | 10분 |
| 토큰 유효기간 | 30일 |
| 비밀번호 해싱 | bcrypt (salt: 10) |

### 2.5 비밀번호 재설정
- 이메일 + 휴대폰 번호 일치 확인 필요
- 새 비밀번호: 6자리 숫자

### 2.6 프로필 필수 정보
회원이 설문 참여 및 포인트 적립을 하려면 다음 정보가 필수입니다:
- 연령대
- 성별
- 거주 지역 (시/도, 구/군)

## 3. 설문 투표 시스템

### 3.1 설문 카테고리
| 카테고리 | 색상 | 특징 | 인증 요구 |
|----------|------|------|----------|
| Fun Poll | 노란색 | 가벼운 주제 | 회원 전용 |
| Life Poll | 초록색 | 생활 관련 | 회원 전용 |
| Deep Poll | 빨간색 | 익명 보장 | 회원 전용 |
| Enterprise | 파란색 | B2B 시장조사 | 비회원 허용 |
| Politics | 보라색 | 정치 관련 | 회원 전용 |

### 3.2 질문 유형
| 유형 | 설명 |
|------|------|
| single_choice | 단일 선택 |
| multiple_choice | 복수 선택 |
| text | 자유 서술형 |

### 3.3 설문 참여 흐름
```
[설문 목록] → [설문 선택] → [참여 기록 생성] → [응답 제출]
                                                    ↓
                                            [경험치 지급]
                                                    ↓
                                            [레벨업 체크]
                                                    ↓
                                            [로또 티켓 지급]
```

### 3.4 설문 참여 규칙
| 규칙 | 내용 |
|------|------|
| 중복 참여 | 불가 (회원 전용 설문) |
| 공개 설문 | 중복 참여 가능 (Enterprise) |
| 프로필 필수 | 미완료 시 참여 불가 |

### 3.5 설문 응답 저장
- 응답은 JSON 형식으로 저장
- 익명 설문의 경우 사용자 ID 비노출
- 통계 분석용 메타데이터 자동 수집

### 3.6 경험치 보상
| 활동 | 경험치 |
|------|--------|
| 설문 완료 | 10 XP (기본) |
| 주간 도전 완료 (50개) | 300 XP (보너스) |

## 4. 로또 복권 시스템

### 4.1 시스템 개요
매일 자정(00:00 KST)에 자동 추첨되는 숫자 맞추기 게임입니다.

### 4.2 티켓 획득 방법
| 방법 | 티켓 수 |
|------|---------|
| 회원가입 | 5장 |
| 레벨업 | 레벨당 1장 |
| 친구 추천 (추천인) | 3장 |
| 친구 추천 (피추천인) | 5장 |
| 프로필 완료 (최초) | 3장 |

### 4.3 게임 규칙
| 항목 | 내용 |
|------|------|
| 번호 범위 | 1 ~ 40 |
| 선택 개수 | 5개 |
| 중복 선택 | 불가 |
| 추첨 시간 | 매일 00:00 KST |

### 4.4 당첨 기준 및 상금
| 맞춘 개수 | 상금 (포인트) |
|----------|--------------|
| 5개 | 50,000P |
| 4개 | 5,000P |
| 3개 | 500P |
| 2개 이하 | 미당첨 |

### 4.5 추첨 프로세스
```
[00:00 자동 추첨 시작]
        ↓
[당첨 번호 5개 생성 (1-40)]
        ↓
[티켓별 당첨 여부 확인]
        ↓
[당첨자 포인트 자동 지급]
        ↓
[추첨 결과 저장]
```

### 4.6 티켓 생성 API
```typescript
POST /api/lottery/manual-ticket
Body: { numbers: [1, 5, 12, 23, 40] }
```

### 4.7 인증 요구사항
- 게스트: 로또 기능 사용 불가
- 회원: 프로필 완료 후 사용 가능

## 5. 포인트 리워드 시스템

### 5.1 포인트 획득 방법
| 활동 | 포인트 |
|------|--------|
| 로또 당첨 (3개) | 500P |
| 로또 당첨 (4개) | 5,000P |
| 로또 당첨 (5개) | 50,000P |
| 설문 참여 | 설문별 상이 |

### 5.2 포인트 사용
| 사용처 | 설명 |
|--------|------|
| 리워드 상품 구매 | 기프티콘, 상품권 등 |
| 친구에게 전송 | P2P 전송 가능 |

### 5.3 포인트 원장 시스템
모든 포인트 거래는 `point_ledger` 테이블에 기록됩니다.

| 필드 | 설명 |
|------|------|
| userId | 사용자 ID |
| delta | 변동량 (+/-) |
| reason | 거래 사유 |
| balanceAfter | 거래 후 잔액 |

### 5.4 포인트 잔액 구조
```typescript
{
  available: number,    // 사용 가능 포인트
  onHold: number,       // 보류 중 (주문 대기)
  totalEarned: number,  // 총 획득 포인트
  totalSpent: number    // 총 사용 포인트
}
```

### 5.5 리워드 주문 흐름
```
[상품 선택] → [포인트 홀드] → [주문 생성] → [관리자 승인]
                                                ↓
                                        [상품권 발급]
                                                ↓
                                        [포인트 최종 차감]
```

## 6. 레벨 경험치 시스템

### 6.1 레벨 계산 공식
```
레벨 = Math.floor(경험치 / 100) + 1
최대 레벨 = 100
최대 경험치 = 9,900
```

### 6.2 경험치 획득
| 활동 | 경험치 |
|------|--------|
| 설문 완료 | 10 XP |
| 주간 도전 완료 | 300 XP |

### 6.3 레벨업 보상
| 보상 | 내용 |
|------|------|
| 로또 티켓 | 레벨당 1장 |

### 6.4 연속 참여 보너스
| 연속 일수 | 보너스 |
|----------|--------|
| 7일 | '연속왕' 배지 |
| 30일 | '마라톤러' 배지 |

### 6.5 배지 시스템
| 배지명 | 획득 조건 |
|--------|----------|
| 첫걸음 | 설문 10개 완료 |
| 투표러 | 설문 50개 완료 |
| 투표왕 | 설문 100개 완료 |
| 연속왕 | 7일 연속 참여 |
| 마라톤러 | 30일 연속 참여 |

### 6.6 주간 도전
- **목표**: 일주일 내 50개 설문 완료
- **보상**: 300 경험치 + 로또 티켓 1장

## 7. 친구 추천 시스템

### 7.1 추천 코드 구조
```
형식: POLLI-XXXXXX (6자리 영숫자)
유효기간: 무제한
사용 횟수: 1회 (피추천인당)
```

### 7.2 추천 보상
| 대상 | 보상 |
|------|------|
| 추천인 | 로또 티켓 3장 |
| 피추천인 | 로또 티켓 5장 |

### 7.3 추천 흐름
```
[추천인] → [추천 코드 생성]
                ↓
        [피추천인에게 공유]
                ↓
[피추천인] → [회원가입 후 코드 입력]
                ↓
        [양측 보상 지급]
```

### 7.4 API 엔드포인트
| 엔드포인트 | 메서드 | 설명 |
|-----------|--------|------|
| /api/referral/code | GET | 내 추천 코드 조회 |
| /api/referral/use | POST | 추천 코드 사용 |
| /api/referral/my-referrals | GET | 내가 추천한 목록 |

### 7.5 제한 사항
- 자기 자신 추천 불가
- 이미 사용된 코드 재사용 불가
- 한 계정당 한 번만 추천 코드 사용 가능
